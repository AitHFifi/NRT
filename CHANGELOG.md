# Changelog

All notable changes to the NRT Gabon platform will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-10

### Added
- **Cinematic Pinned Hero Experience**: Multi-layered cockpit and cloud parallax powered by GSAP ScrollTrigger and Lenis smooth scrolling.
- **Interactive Gabon Route Map**: Custom SVG geospatial projection mapping Libreville hub to all major provincial airports (Port-Gentil, Franceville, Moanda, Oyem, Makokou, Mouila, Tchibanga) with animated flight vectors.
- **Dual-Mode Booking Engine**: Comprehensive booking suite supporting scheduled commercial flights and VIP private charter inquiries with seat preview.
- **Aircraft Fleet Showcase**: Dynamic fleet viewer with technical specifications, 360-degree hotspot inspection, radar range circle visualization, and cabin seat maps.
- **Live Flight Tracker**: Real-time departure and arrival status board with status badges (On Time, Scheduled, Boarding).
- **Specialized Aviation Services**: Highlighting corporate energy/mining shuttles, air ambulance medevac, and cargo logistics.
- **Bilingual Support**: Instant toggle between French (Français) and English with XAF / EUR currency conversion.
- **CI Automation**: GitHub Actions pipeline for continuous ESLint validation and Next.js production builds.
- **Community Templates**: Comprehensive issue templates and PR checklists for open collaboration.
